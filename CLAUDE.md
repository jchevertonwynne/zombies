# Zombies

A single-player, first-person zombies game inspired by CoD: World at War and Black Ops 1, built with Bevy 0.20 + avian3d 0.8.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on jchevertonwynne/zombies, used through the `gh` CLI; wayfinder maps are `wayfinder:map` issues with sub-issue tickets. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
