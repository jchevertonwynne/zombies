# Every Map is built at the world origin

Every Map is authored and built centred on the world origin along x: its plan's middle is at x = 0, with floors at their usual heights. The current Map comes from the `MapId` resource, which is set before a Run builds. This supersedes the part of [ADR 0005](0005-each-map-has-its-own-part-of-the-world.md) that built each Map in its own patch of the world (the Village at -200, the Quarry at +200, the Cove at -400, the Dam at +400, the Polder at +600) so no two Maps' Zone volumes overlapped. ADR 0005's other points stand: Zones are variants of the one `ZoneId` enum and each knows its Map (`ZoneId::map`), every window sits in the one `WINDOWS` table, and per-Map systems read from the current `Layout`.

The offsets had grown costly. Positions far from the origin outgrew the Co-op wire format; every Map's data was written with its offset added to every x (and each new Map had to be placed further out, losing float precision and making positions hard to read in logs and tests). Overlapping Maps cost something too: a point no longer says which Map it is on, so every lookup from a position to a Zone takes the Map. `zone_at(map, point)` and `track_zone` look only at that Map's Zones, wall-face sampling in the builder only cuts at that Map's Zones, and `nearest_window(map, at)` only at that Map's windows. Only z stays authored where it was: a Map's plan is not centred on z = 0, because a Map's z is already small and its authored coordinates are all relative to the Map's own start.

On the wire, positions are still told from the plan's middle (`wire_origin`), which is now close to the origin for every Map. We kept that encoding: it costs nothing and keeps a Map's whole plan inside the `i16` range wherever its middle falls.
