# Developer mode is a layer on Classic, and any Cheat taints the Run

Developer mode is a separate plugin that works only once a Cheat is used. It reaches Classic only through seams ([ADR 0002](0002-gauntlet-layers-on-classic.md), [ADR 0007](0007-gauntlet-asks-classic-through-generic-requests.md)). Each seam it needs is a neutral Classic message or marker with a meaning outside developer mode: a Round request, a `GiveWeapon` message, an invincibility marker that Gauntlet's Grit does not share, more spawn kinds, an open-every-Door request and a noclip flag on the movement step. It never adds a dev-mode branch to Classic, and it never writes a component a layer rewrites.

There is no launch flag and no Settings toggle: the option is in every build and a normal Run shows nothing. The first Cheat pressed **taints the Run** for good, and a tainted Run writes nothing at its end. The taint is one Classic-owned, one-way flag per Run, reset on entering Playing and checked at the four places a Run's end writes (`record_run`, `pay_scrip`, `earn_commendations` and the `has_won` set in `log_run`). We chose this over marking cheated Runs in the Run Record because it needs no change to the save format and no Record ever has to be told apart. Blocking the save directory alone would not do: `RecordsFile` and `GauntletFile` are changed in memory first and the next honest write would flush them.

In Co-op ([ADR 0003](0003-coop-network-layer.md)) the Host chooses Off, On or Host only in the Room, and can change it during the Run. Every Cheat is a client request the Host judges, and a request the setting forbids is dropped. The taint is set by the Host for every Player and is replayed to a Rejoiner. Noclip is the one predicted Cheat: a `Step` button bit that the Host replays and ignores for a Player without access. Personal Cheats are kept by Seat so a Rejoiner keeps them. Cheat requests and the noclip bit break the wire format, so the ALPN and `Hello` version are bumped. Decided on the [Developer mode map](https://github.com/jchevertonwynne/zombies/issues/444), with the research in `research/dev-mode-seams` and `research/run-persistence`.
