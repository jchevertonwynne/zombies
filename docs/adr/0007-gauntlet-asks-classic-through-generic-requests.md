# Gauntlet may ask Classic for generic effects, and mark Classic entities with generic factors

Besides [ADR 0002](0002-gauntlet-layers-on-classic.md)'s three ways, Gauntlet may (4) send **request messages** that Classic handles, such as casting an element Effect, spawning a Zombie of a kind, healing the Player or a Zombie, or resetting the Knife cooldown, and (5) set **generic components or resources** that Classic reads, such as a Zombie's speed or damage-taken factor, a "would Down" guard, or a set of reserved Round numbers. Each request and factor must be meaningful without Gauntlet: Classic either uses it itself (the Sapper is a `Heavyweight`), or keeps it at a neutral default (factor 1.0, empty set, `None`). Classic code still never names a Gauntlet concept. We chose this over letting Gauntlet mutate Classic components directly, so that Classic owns its own invariants (health, Planks, Points, Loadout), and over `Mode` checks, for ADR 0002's reasons. Decided in [Assemble the Gauntlet v2 spec](https://github.com/jchevertonwynne/zombies/issues/100).
