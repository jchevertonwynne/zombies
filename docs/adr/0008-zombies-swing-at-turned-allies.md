# Zombies swing at Turned allies

A Zombie with no Player in its reach swings at the nearest Turned ally in its reach, with its usual reach, wind-up, line-of-sight check and cooldown, and a landed swing sends `TurnedAllyHit { ally, by }`. The swing hurts nothing: the ally keeps its lifetime and kill limit. The Player always comes first, and a Zombie still never hunts an ally down; it only swings at one that has come to it. This is a deliberate change to Classic Zombie behaviour, and an exception to the Gauntlet v2 spec's "Classic gameplay doesn't change" ([ADR 0007](0007-gauntlet-asks-classic-through-generic-requests.md)): before it, Zombies ignored Turned allies, so nothing could send `TurnedAllyHit` for the Galvanised Dead Duo Boon to react to. We chose a real swing over a Gauntlet-side "a Zombie stood near an ally" proxy so the message means what it says, and kept it harmless so Classic Runs and their Records stay comparable. Decided on [Gauntlet v2 slice 3: Duo Boons](https://github.com/jchevertonwynne/zombies/issues/309).
